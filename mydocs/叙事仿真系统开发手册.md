# 叙事仿真系统开发手册

> 面向执行者（Kimi Code）的完整开发指南。本手册自包含：架构、契约、已有代码、环境搭建、里程碑任务与验收标准全部在此。
> 项目代号：**narrative-sim**。

---

## 1. 项目目标

构建一个「叙事仿真工具」：

1. **自动资产调研**：基于 SearXNG + Crawl4AI + GPT-Researcher，自动调研人物长相、服饰、场景、历史背景，生成结构化资产入库；
2. **持久化世界模拟**：WorldSeed 维护场景、道具、角色外貌、记忆状态；
3. **多角色仿真**：TinyTroupe 驱动角色心智、对话、行为；
4. **事件导出**：输出标准化剧情事件流（JSONL），可直接接入 AI 视频生成管线；
5. **MCP 原生支持**：封装为 MCP Server，可被 dsh / Kimi Code 作为工具调用。

LLM 统一使用 **DeepSeek Flash**（OpenAI 兼容协议，`base_url=https://api.deepseek.com`，模型名 `deepseek-flash`）。

---

## 2. 总体架构

四层结构，三条数据契约：

```
┌─────────────────────────────────────────────────┐
│  L4 接入层：MCP Server（FastMCP）                │  ← dsh / Kimi Code 调用入口
├─────────────────────────────────────────────────┤
│  L3 编排层：Orchestrator（本项目核心代码）         │  ← 唯一的胶水代码所在
├──────────────┬──────────────┬───────────────────┤
│  L2a 调研管线 │  L2b 仿真管线 │  L2c 导出管线      │
│  SearXNG      │  WorldSeed    │  事件流 → 视频管线  │
│  Crawl4AI     │  TinyTroupe   │  (JSONL)          │
│  GPT-Researcher│             │                   │
├─────────────────────────────────────────────────┤
│  L1 存储层：SQLite（资产库 + 世界状态 + 事件日志）  │
└─────────────────────────────────────────────────┘
```

**核心原则（必须遵守）**：

- 各开源项目之间**永不直接互相 import**，所有信息经 Orchestrator 转手；
- 数据库是各管线之间的共享记忆，**只有 Orchestrator 的 `store.py` 可以读写数据库**；
- 两条契约（资产 Schema / 事件 Schema）是所有模块的接缝，入库/导出时必须经 `jsonschema` 校验（"海关"职责）；
- 模型名、API key 只出现在 `.env` / `config.ini`，**不落代码**；
- 不使用 Docker，存储用 SQLite（Python 内置）。

### Orchestrator 的六项职责

1. **流程编排**：`research_assets → build_world → run_simulation → export_events` 状态机，失败重试/断点续跑；
2. **契约执行**：入库前、导出前做 Schema 校验，不合格拒绝；
3. **适配隔离**：每个外部库封装在适配器后（如 `PersonaBackend` Protocol），业务代码不直接依赖第三方 API；
4. **存储读写**：数据库唯一入口（`store.py`）；
5. **成本管控**：按 `run_id` 聚合 token 用量，LLM 分级路由（fast/smart）；
6. **对上暴露**：MCP Server 是 Orchestrator 方法的薄封装，不含业务逻辑。

## 3. 数据契约（已定稿，勿随意改动）

### 3.1 资产契约 `schemas/asset.schema.json`

关键字段：

| 字段 | 说明 |
|---|---|
| `asset_id` | 全局唯一，pattern `^(char|prop|scene|epoch)_[a-z0-9_]+$`，**事件流和视频管线只引用此 ID** |
| `type` | `character / prop / scene / epoch` |
| `appearance` | 外貌/服饰/道具，`visual_prompt` 为预生成的英文视觉提示词骨架；character 必填 |
| `persona_spec` | character 必填：`age / occupation / personality / beliefs / speech_style`，直接映射 TinyPerson |
| `historical_context` | 时代、地域、`sources`（来源 URL，回溯纠错用） |
| `reference_images` | 参考图路径/URI，视频管线跨镜头一致性依赖它 |
| `provenance` | `researched_at / retriever / model / confidence`，必填 |
| `status` | `draft / verified / deprecated` |

### 3.2 事件契约 `schemas/event.schema.json`

JSONL 一行一个事件，关键字段：

| 字段 | 说明 |
|---|---|
| `event_id` | pattern `^e[0-9]{4,}$` |
| `run_id` + `tick` + `seq` | 排序键：一次仿真运行 → 回合 → 回合内序号 |
| `type` | `dialogue / action / scene_change / narration / inner_voice` |
| `characters` | **只存 asset_id 引用，不放外貌文本** |
| `location` | scene 类资产 ID |
| `cause_refs` | 触发本事件的上游 event_id，剧情回溯用 |
| `shot_hint` | 镜头提示骨架：`camera / duration_s / style`，给视频管线用 |

完整 Schema 见附录 A，或项目目录 `schemas/`。

    def act(self, persona_spec: dict, visible_state: dict) -> dict:

        # 把 visible_state 用 make_agent_accessible / listen 喂给 TinyPerson
        # 调 person.act() 拿动作，解析为 {"kind","content","emotion"} 返回

要点：

- `TinyPerson` 从 `persona_spec` 构建（`define("age", ...)` 等）；
- 每个角色的 `TinyPerson` 实例按 `asset_id` 缓存复用，**跨回合保持记忆连续性**；
- 动作解析失败时走重试（TinyTroupe 自带 ActionGenerator 质量校验，保持开启）；
- 在 `run_minimal_chain.py` 同级新增 `scripts/run_real_chain.py`，仅替换 backend 参数。

验收：真后端跑 4 回合产出 ≥5 条事件，契约校验通过，M1 不回归。

### M3 调研管线自动化

任务：实现 `orchestrator/research.py`：

1. **SearXNG**：原生安装（参考官方安装脚本，或 `pip install searxng` 后以 uwsgi/直接方式起服务，端口 8080），`.env` 中 `SEARX_URL` 指向它；
2. **GPT-Researcher**：`pip install gpt-researcher`，`RETRIEVER=searx`（.env 已配），调 `GPTResearcher(query).conduct_research()`；
3. **Crawl4AI**：`pip install crawl4ai`，对 GPT-Researcher 返回的重点 URL 做深度抓取 + LLM 抽取；
4. 调研结果经 `llm.chat_json()` 结构化抽取为资产 JSON → `store.put_asset()` 校验入库；
5. **语义去重**：入库前对 `name + appearance` 做向量相似度检查（可先用 SQLite + 简单 embedding 缓存实现）。

验收：给一个人物/场景查询词，自动产出符合契约的资产入库，`provenance.retriever="searxng+crawl4ai"`，`sources` 非空。

### M4 接入 WorldSeed

任务：实现 `orchestrator/world.py`：

- 从资产库组装 WorldSeed YAML 配置（角色、场景、信息不对称规则）；
- `simulation.py` 的 tick 循环替换为 WorldSeed 引擎驱动，**事件翻译逻辑（emit/shot_hint 映射）保留复用**；
- 每回合结束把世界状态快照写入 `worlds.state`（断点续跑基础）；
- WorldSeed 是唯一世界状态真相源，TinyPerson 的记忆每回合从它同步。

## 6. 已知坑与约束

1. **TinyTroupe API 不稳定**：官方明示仍在大幅迭代。所有 TinyTroupe 调用封在适配器内，pin 到具体 commit；
2. **结构化输出漂移**：非 OpenAI 模型偶发格式漂移，TinyTroupe 的 ActionGenerator 质量校验保持开启，外加 orchestrator 的 Schema 校验双保险；
3. **成本**：多角色仿真 token 消耗大。DeepSeek Flash 有缓存命中低价与闲时定价，批量仿真尽量错峰；用 TinyTroupe 的 cost stats 按 run_id 记账（写入 `runs.token_cost`）；
4. **合规**：TinyTroupe 明确仅限研究与仿真用途，生成内容需人工复核后再用于正式产出；
5. **沙箱无 GitHub 直连时**：用 Gitee 镜像（见 4.2）。

### A.1 `orchestrator/store.py`

```python
"""存储层：SQLite 读写 + 契约校验（orchestrator 是唯一入口）。"""
import json
import sqlite3
from pathlib import Path

import jsonschema

ROOT = Path(__file__).resolve().parent.parent
SCHEMAS = ROOT / "schemas"


def _load_schema(name: str) -> dict:
    return json.loads((SCHEMAS / name).read_text(encoding="utf-8"))


class Store:
    def __init__(self, db_path: str):
        self.conn = sqlite3.connect(db_path)
        self.conn.row_factory = sqlite3.Row

    def put_asset(self, asset: dict) -> str:
        jsonschema.validate(asset, _load_schema("asset.schema.json"))
        self.conn.execute(
            "INSERT OR REPLACE INTO assets(asset_id, type, name, status, payload) VALUES(?,?,?,?,?)",
            (asset["asset_id"], asset["type"], asset["name"],
             asset.get("status", "draft"), json.dumps(asset, ensure_ascii=False)),
        )
        self.conn.commit()
        return asset["asset_id"]

    def get_asset(self, asset_id: str) -> dict:
        row = self.conn.execute("SELECT payload FROM assets WHERE asset_id=?", (asset_id,)).fetchone()
        if not row:
            raise KeyError(f"资产不存在: {asset_id}")
        return json.loads(row["payload"])

    def create_run(self, run_id: str, world_id: str) -> None:
        self.conn.execute("INSERT OR IGNORE INTO worlds(world_id, config) VALUES(?, '')", (world_id,))
        self.conn.execute("INSERT INTO runs(run_id, world_id) VALUES(?,?)", (run_id, world_id))
        self.conn.commit()

    def put_event(self, event: dict) -> None:
        jsonschema.validate(event, _load_schema("event.schema.json"))
        self.conn.execute(
            "INSERT INTO events(event_id, run_id, tick, seq, type, payload) VALUES(?,?,?,?,?,?)",
            (event["event_id"], event["run_id"], event["tick"], event.get("seq", 0),
             event["type"], json.dumps(event, ensure_ascii=False)),
        )
        self.conn.commit()

    def export_events(self, run_id: str) -> list[dict]:
        rows = self.conn.execute(
            "SELECT payload FROM events WHERE run_id=? ORDER BY tick, seq", (run_id,)
        ).fetchall()
        return [json.loads(r["payload"]) for r in rows]
```

### A.3 `orchestrator/simulation.py`

```python
"""最小仿真循环：WorldSeed 的占位实现。"""
import json
from datetime import datetime, timezone

from .persona import PersonaBackend
from .store import Store

_SHOT_BY_KIND = {
    "dialogue": {"camera": "medium", "duration_s": 4},
    "action": {"camera": "wide", "duration_s": 3},
    "inner_voice": {"camera": "close_up", "duration_s": 2.5},
    "scene_change": {"camera": "wide", "duration_s": 3},
    "narration": {"camera": "pan", "duration_s": 3},
}


def run_simulation(store, run_id, world_id, character_ids, location_id,
                   ticks, backend: PersonaBackend) -> list[dict]:
    store.create_run(run_id, world_id)
    personas = []
    for cid in character_ids:
        asset = store.get_asset(cid)
        spec = dict(asset.get("persona_spec", {}), name=asset["name"])
        personas.append((cid, spec))

    events: list[dict] = []
    n = 0
    prev_by_char: dict[str, str] = {}

    def emit(tick, seq, etype, content, chars, emotion="", cause=None):
        nonlocal n
        n += 1
        ev = {
            "event_id": f"e{n:04d}", "run_id": run_id, "tick": tick, "seq": seq,
            "type": etype, "characters": chars, "location": location_id,
            "content": content, "emotion": emotion,
            "cause_refs": cause or [],
            "shot_hint": _SHOT_BY_KIND.get(etype, {"camera": "medium", "duration_s": 3}),
            "created_at": datetime.now(timezone.utc).isoformat(),
        }
        store.put_event(ev)
        events.append(ev)

    scene = store.get_asset(location_id)
    emit(0, 0, "scene_change",
         f"场景：{scene['name']}。{scene.get('appearance', {}).get('visual_prompt', '')}",
         character_ids)

    for tick in range(1, ticks + 1):
        for seq, (cid, spec) in enumerate(personas, start=1):
            action = backend.act(spec, {"tick": tick, "location": location_id})
            emit(tick, seq, action["kind"], action["content"], [cid],
                 action.get("emotion", ""),
                 [prev_by_char[cid]] if cid in prev_by_char else [])
            prev_by_char[cid] = events[-1]["event_id"]

    return events


def export_jsonl(store: Store, run_id: str, out_path: str) -> str:
    events = store.export_events(run_id)
    with open(out_path, "w", encoding="utf-8") as f:
        for ev in events:
            f.write(json.dumps(ev, ensure_ascii=False) + "\n")
    return out_path
```

### A.4 `orchestrator/llm.py`

```python
"""统一 LLM 接入：DeepSeek Flash（OpenAI 兼容协议）。"""
import os
from functools import lru_cache

from dotenv import load_dotenv
from openai import OpenAI

load_dotenv()


@lru_cache
def client() -> OpenAI:
    return OpenAI(
        api_key=os.environ["DEEPSEEK_API_KEY"],
        base_url=os.getenv("DEEPSEEK_BASE_URL", "https://api.deepseek.com"),
    )


def chat(messages: list[dict], tier: str = "fast", **kwargs) -> str:
    model = os.environ["MODEL_SMART" if tier == "smart" else "MODEL_FAST"]
    resp = client().chat.completions.create(model=model, messages=messages, **kwargs)
    return resp.choices[0].message.content


def chat_json(messages: list[dict], tier: str = "fast") -> dict:
    import json
    out = chat(messages, tier=tier, response_format={"type": "json_object"})
    return json.loads(out)
```

### A.5 `db/init_db.py`

```python
"""初始化 SQLite 存储：资产库 / 世界状态 / 事件日志。"""
import sqlite3, sys
from pathlib import Path

DDL = """
CREATE TABLE IF NOT EXISTS assets (
    asset_id   TEXT PRIMARY KEY,
    type       TEXT NOT NULL CHECK (type IN ('character','prop','scene','epoch')),
    name       TEXT NOT NULL,
    status     TEXT NOT NULL DEFAULT 'draft',
    payload    TEXT NOT NULL,
    created_at TEXT NOT NULL DEFAULT (datetime('now')),
    updated_at TEXT NOT NULL DEFAULT (datetime('now'))
);
CREATE INDEX IF NOT EXISTS idx_assets_type ON assets(type);

CREATE TABLE IF NOT EXISTS worlds (
    world_id   TEXT PRIMARY KEY,
    config     TEXT NOT NULL,
    state      TEXT,
    tick       INTEGER NOT NULL DEFAULT 0,
    created_at TEXT NOT NULL DEFAULT (datetime('now')),
    updated_at TEXT NOT NULL DEFAULT (datetime('now'))
);

CREATE TABLE IF NOT EXISTS runs (
    run_id     TEXT PRIMARY KEY,
    world_id   TEXT NOT NULL REFERENCES worlds(world_id),
    status     TEXT NOT NULL DEFAULT 'running',
    token_cost REAL DEFAULT 0,
    started_at TEXT NOT NULL DEFAULT (datetime('now')),
    ended_at   TEXT
);

CREATE TABLE IF NOT EXISTS events (
    event_id   TEXT PRIMARY KEY,
    run_id     TEXT NOT NULL REFERENCES runs(run_id),
    tick       INTEGER NOT NULL,
    seq        INTEGER NOT NULL DEFAULT 0,
    type       TEXT NOT NULL,
    payload    TEXT NOT NULL,
    created_at TEXT NOT NULL DEFAULT (datetime('now'))
);
CREATE INDEX IF NOT EXISTS idx_events_run ON events(run_id, tick, seq);
"""


def init(db_path: str) -> str:
    Path(db_path).parent.mkdir(parents=True, exist_ok=True)
    with sqlite3.connect(db_path) as conn:
        conn.executescript(DDL)
    return db_path


if __name__ == "__main__":
    path = init(sys.argv[1] if len(sys.argv) > 1 else "narrative_sim.db")
    print(f"数据库已初始化: {path}")
```
