# Feature Specification: 恢复语义记忆（本地嵌入服务接入）

**Feature Branch**: `003-semantic-memory-restore`

**Created**: 2026-10-19

**Status**: Draft

**Input**: User description: "使用量化模型（litert-lm API 服务，eg2-text-270m，OpenAI 兼容 /v1/embeddings，127.0.0.1:9379）恢复 TinyTroupe 语义记忆：llama-index 的 embedding 指向该服务，撤掉 002 的本地列表降级；服务不可用时优雅降级不阻塞仿真；服务地址走环境变量。"

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 语义检索恢复 (Priority: P1)

嵌入服务可用时，真后端角色的语义记忆真正工作：事件经向量化沉淀，
角色行动时系统按当前情境捞出语义相关的旧记忆放进 prompt，
长仿真中早期事件不再被遗忘。

**Why this priority**: 这是本特性的全部价值 —— 002 里语义记忆被降级为
本地列表（只存不检），角色实际上没有"按意思回忆"的能力。

**Independent Test**: 嵌入服务在线时跑真后端链路，验证语义记忆连接器
确实经由嵌入服务完成了存取（而非静默走了降级路径），且事件流照常产出。

**Acceptance Scenarios**:

1. **Given** 嵌入服务在线、真后端链路运行，**When** 角色完成若干回合行动，
   **Then** 语义记忆的写入与召回经由嵌入服务完成（日志/探针可证），
   事件流正常产出且契约校验通过
2. **Given** 角色在第 1 回合经历了某事件，**When** 若干回合后当前情境与该事件
   语义相关，**Then** 角色的召回结果中包含该旧记忆（可用直接调召回接口的
   探针测试验证，不依赖 LLM 表现）

---

### User Story 2 - 服务离线时优雅降级 (Priority: P2)

嵌入服务未启动或不可达时，真后端链路自动降级为 002 的本地列表行为，
仿真照常完成，并在输出中明确告知"语义检索已降级"。

**Why this priority**: 嵌入服务是外部常驻进程，不能成为仿真的硬依赖 ——
否则"忘了启动服务"就阻塞一切。降级保证链路健壮性。

**Independent Test**: 嵌入服务停止状态下跑真后端链路（有 LLM 密钥），
退出码 0、输出含降级提示；离线单元测试模拟服务不可达验证降级路径。

**Acceptance Scenarios**:

1. **Given** 嵌入服务未启动，**When** 运行真后端链路，
   **Then** 链路正常完成、输出明确降级提示、行为与 002 一致
2. **Given** 嵌入服务中途宕机，**When** 单次嵌入调用失败，
   **Then** 错误被拦截、不导致仿真崩溃（与 002 的"忽略并继续"一致）

---

### User Story 3 - 配置可移植 (Priority: P3)

换机器或改端口时，只改环境变量即可指向另一个嵌入服务实例，
代码与配置文件中不出现硬编码的服务地址。

**Why this priority**: 宪章原则 VI 与 T021 的教训 —— 服务地址必须可重定向。

**Independent Test**: 用环境变量指向一个 mock 嵌入端点，链路使用新地址。

**Acceptance Scenarios**:

1. **Given** 未设置嵌入服务地址环境变量，**When** 启动真后端，
   **Then** 走降级路径或明确报错（按设计口径），无硬编码地址被使用

---

### Edge Cases

- 嵌入服务在线但模型名不匹配：启动预检发现，明确报错而非静默产生错误向量
- 嵌入服务响应缓慢：嵌入调用有超时上限，超时走降级，不拖垮仿真节奏
- 文本为空或超长：空文本不发起嵌入调用；超长文本按模型上下文上限截断

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 嵌入服务可用时，角色语义记忆的写入与召回 MUST 经由该服务完成
  向量化；MUST NOT 静默走降级路径
- **FR-002**: 系统 MUST 在使用嵌入服务前做可达性与模型身份预检
  （端点在线 + 模型标识匹配），失败即按 US2 降级
- **FR-003**: 嵌入服务地址、模型标识 MUST 从环境变量读取，MUST NOT 硬编码
  （宪章原则 VI）；真实密钥文件不入库
- **FR-004**: 嵌入服务不可用时 MUST 自动降级为 002 的本地列表行为，
  仿真照常完成，且输出明确降级提示
- **FR-005**: 单次嵌入调用 MUST 有超时上限；超时或失败 MUST NOT 使仿真崩溃
- **FR-006**: 本特性 MUST NOT 改动资产/事件契约；M1、M2 既有验收 MUST 不回归
- **FR-007**: 嵌入服务本身（litert-lm 及其启动脚本）MUST NOT 进入本项目仓库；
  仓库只记录接入方式（环境变量 + 文档）
- **FR-008**: 所有 TinyTroupe 接触面 MUST 仍只在适配器模块内（宪章原则 II），
  嵌入服务的接入代码同样如此

### Key Entities *(include if feature involves data)*

- **嵌入服务描述**：地址、模型标识、超时上限 —— 全部来自环境变量，无持久化
- **语义记忆条目**：TinyTroupe 内部结构，本特性不改变其形态，只恢复其
  向量化通道

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 服务在线时，语义记忆的存与取 100% 经由嵌入服务完成
  （探针可验证），真链路验收通过（≥5 事件、契约全过）
- **SC-002**: 服务离线时，真链路仍 100% 完成验收，且输出含降级提示
- **SC-003**: 单次嵌入调用超过 10 秒即判定超时并降级，不阻塞仿真
- **SC-004**: M1 / M2 回归 100% 通过（离线测试套件全绿）
- **SC-005**: 嵌入相关代码 100% 位于适配器模块内，仓库无硬编码服务地址

## Assumptions

- 嵌入服务为 litert-lm serve（eg2-text-270m，OpenAI 兼容 `/v1/embeddings`），
  由用户按需启动（启动脚本在仓库外，已交付）；本项目不管理其生命周期
- 默认服务地址为 `http://127.0.0.1:9379/v1`，但仅以环境变量默认值文档化，
  不落代码（.env.example 提供键位）
- 嵌入向量维度（768）与 TinyTroupe 语义连接器的兼容性在 plan 阶段探针验证；
  如 llama-index 的 OpenAI 嵌入组件对自定义端点/模型名有额外限制，
  允许在适配器内实现一个薄嵌入客户端（只读 `/v1/embeddings`）
- 本特性不做：多模态嵌入（图像/音频）、嵌入结果缓存、量化与全精度向量
  一致性对比（可在本特性完成后作为附加验证）
- 真链路验收仍需 DeepSeek 密钥（沿用 002 环境）
