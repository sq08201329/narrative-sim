# Contract: 最小链路 CLI

## 命令

```bash
uv run python scripts/run_minimal_chain.py
```

## 前置条件

- 已执行 `uv sync`（依赖已装、虚拟环境就绪）
- 无需 `.env`、无需网络、无需任何密钥

## 行为契约

1. 幂等初始化数据库（默认 `narrative_sim.db`，已 gitignore）
2. 入库示例资产：1 名角色 + 1 个场景（满足资产契约）
3. 以 Mock 角色后端运行 4 回合仿真
4. 导出事件流到 `exports/`（JSONL，每行一个事件）
5. 逐条复验事件契约
6. 全程打印进度，最后一行输出：`验收通过`

## 退出码

| 退出码 | 含义 |
|--------|------|
| 0 | 全链路完成，全部事件通过契约校验 |
| 非 0 | 任一环节失败；stderr 输出指明失败环节与原因 |

## 确定性

同一检出重复运行：事件序列（除 `created_at` 时间戳外）逐字节一致。
